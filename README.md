# NewsDay 📰

**Гиперлокальные новости Ташкента** — прототип MVP (web-first) на базе [PRD_NewsDay](../PRD_NewsDay.md).

Единая новостная лента с фильтром по районам города, категориям и мультиязычностью — то, чего нет в разрозненных Telegram-каналах.

## Возможности прототипа

- 🌐 **4 языка**: узбекский (латиница + кириллица), русский, английский — с мгновенным переключением
- 📍 **Гиперлокальность**: фильтр ленты по 11 районам Ташкента
- 🏷️ **Категории**: транспорт, ЖКХ, происшествия, события, город, экономика
- 🔍 **Поиск** по заголовкам и описаниям
- 🔖 **Закладки** (сохраняются в браузере)
- ⚡ **Срочные новости** (breaking) и метка верифицированных источников
- 🌤️ Сайдбар: погода, популярное, подписка на дайджест
- 📱 Адаптивная вёрстка (desktop / mobile)

## Технологии

Чистый **HTML + CSS + JavaScript**, без сборки и зависимостей. Открывается двойным кликом или как статический сайт (GitHub Pages).

```
newsday/
├── index.html   # разметка и стили
├── data.js      # i18n, районы, категории, мок-новости (4 языка)
├── app.js       # логика: фильтры, поиск, закладки, модалка статьи
└── README.md
```

## Запуск локально

Просто откройте `index.html` в браузере. Либо поднимите статический сервер:

```bash
# любой из вариантов
python -m http.server 8080
npx serve .
```

## Публикация (GitHub Pages)

Settings → Pages → Deploy from branch → `main` / root. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.
