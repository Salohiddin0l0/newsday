# NewsDay 📰

**Гиперлокальные новости Ташкента** — full-stack прототип по [PRD_NewsDay](../PRD_NewsDay.md): фронтенд + REST API + CMS редакции с модерацией.

Единая новостная лента с фильтром по районам города, категориям и мультиязычностью — то, чего нет в разрозненных Telegram-каналах.

## Возможности

**Сайт (публичная часть)**
- 🌐 4 языка: узбекский (латиница + кириллица), русский, английский
- 📍 Фильтр ленты по 11 районам Ташкента
- 🏷️ Категории: транспорт, ЖКХ, происшествия, события, город, экономика
- 🧩 Разные типы карточек (hero + «Главное», overlay-плитки «Выбор редакции», список) в стиле Kun.uz
- 🔍 Поиск, 🔖 закладки, ⚡ breaking-новости, ✔ метка верифицированных источников
- 🌙 Ночной режим, время публикации в формате `13:32`
- ✉️ Подписка на дайджест (пишется в backend)

**Backend (REST API)**
- Данные хранятся на сервере (файловое JSON-хранилище через слой репозитория)
- Публичное API + защищённое админ-API с токен-авторизацией

**CMS редакции** (`/admin.html`)
- Вход по паролю
- Создание новостей на 4 языках
- Модерация: одобрить / отклонить (статусы `pending` → `published` / `rejected`)
- Удаление, статистика, фильтр по статусу

## Технологии

- **Frontend:** чистый HTML + CSS + JS (без сборки)
- **Backend:** Node.js + Express, ES-модули
- **Хранилище:** JSON-файл (`data/news.json`) через изолированный слой `store.js` — легко заменить на PostgreSQL/SQLite

## Структура

```
newsday/
├── package.json
├── server/
│   ├── server.js      # Express: REST API + отдача статики
│   ├── store.js       # слой доступа к данным (репозиторий)
│   ├── auth.js        # токен-авторизация админа
│   ├── seed.js        # наполнение БД
│   └── seed-data.js   # исходные новости, районы, категории
├── data/
│   └── news.json      # БД (генерируется через seed, в .gitignore)
└── public/
    ├── index.html     # сайт
    ├── app.js         # логика фронтенда (берёт данные из API)
    ├── config.js      # UI-строки (i18n интерфейса)
    └── admin.html     # CMS редакции
```

## Запуск

```bash
npm install       # установить зависимости
npm run seed      # наполнить БД начальными новостями
npm start         # запустить сервер
```

Затем открыть:
- **Сайт:** http://localhost:3000
- **CMS редакции:** http://localhost:3000/admin.html (пароль по умолчанию `admin123`)
- **API health:** http://localhost:3000/api/health

Пароль админа можно задать через переменную окружения `NEWSDAY_ADMIN_PASSWORD`.
Порт — через `PORT`.

## REST API

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/health` | public | статус + статистика |
| GET | `/api/meta` | public | районы и категории |
| GET | `/api/news` | public | опубликованные новости (`?category=&district=&q=`) |
| GET | `/api/news/:id` | public | одна новость |
| POST | `/api/subscribe` | public | подписка на дайджест |
| POST | `/api/auth/login` | public | вход админа → токен |
| GET | `/api/admin/news` | admin | все новости + статистика (`?status=`) |
| POST | `/api/admin/news` | admin | создать |
| PUT | `/api/admin/news/:id` | admin | изменить |
| DELETE | `/api/admin/news/:id` | admin | удалить |
| POST | `/api/admin/news/:id/moderate` | admin | `{action:"approve"\|"reject"}` |

## Статус и следующие шаги

Прототип MVP: контент моковый, авторизация упрощённая (для демо). Дальше по PRD:
- Реальная агрегация источников (гибридная модель) + дедупликация
- Полноценная БД (PostgreSQL) — заменить слой `store.js`
- Хеширование паролей, JWT/сессии, роли (Editor/Moderator/Admin)
- Web Push + email-рассылка дайджеста подписчикам
